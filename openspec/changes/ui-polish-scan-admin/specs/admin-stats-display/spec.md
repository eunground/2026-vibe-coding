## ADDED Requirements

### Requirement: 통계 그리드에서 연체 숫자를 크기로 강조
시스템은 관리자 통계 그리드에서 연체(overdue) 숫자를 나머지 통계 숫자보다 시각적으로 더 크게 표시해야 한다(SHALL). 상태 컬러는 기존 빨강 구분을 유지하며 새 색을 추가하지 않는다(MUST NOT).

#### Scenario: 통계 그리드 표시
- **WHEN** 관리자가 대여 현황 탭에서 통계 그리드를 본다
- **THEN** 연체 숫자가 전체·대여 가능·대여 중 숫자보다 더 큰 크기로 표시된다

#### Scenario: 색상 구분 유지
- **WHEN** 연체 숫자가 강조되어 표시된다
- **THEN** 연체 숫자의 색상은 기존 연체 컬러(빨강)를 그대로 유지한다
