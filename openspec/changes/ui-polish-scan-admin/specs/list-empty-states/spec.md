## ADDED Requirements

### Requirement: 빈 목록은 아이콘+메시지 empty state로 안내
시스템은 비어 있는 목록/표(대여 중 목록·등록 우산 목록·대여 기록)에 대해 아이콘과 안내 메시지를 함께 보여주는 일관된 empty state를 표시해야 한다(SHALL). 데이터가 0건일 때만 렌더되며, 로딩 상태(오버레이 스피너)와 구분되어야 한다(MUST).

#### Scenario: 대여 중 목록이 비어 있음
- **WHEN** 현재 대여 중인 우산이 하나도 없다
- **THEN** 대여 중 목록 영역에 아이콘과 "대여 중인 우산이 없다"는 메시지가 함께 표시된다

#### Scenario: 등록 우산 목록이 비어 있음
- **WHEN** 등록된 우산이 하나도 없다
- **THEN** 우산 목록 영역에 아이콘과 "등록된 우산이 없다"는 메시지가 함께 표시된다

#### Scenario: 대여 기록이 비어 있음
- **WHEN** 대여 기록이 하나도 없다
- **THEN** 기록 표 영역에 아이콘과 "대여 기록이 없다"는 메시지가 함께 표시된다
